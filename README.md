# Projekty w Pythonie

## Zawartość repozytorium

- `blackjack.py` - prosta gra w Blackjacka
- `caesar_cipher.py` - szyfr Cezara, czyli podstawowe szyfrowanie i odszyfrowywanie tekstu
- `hangman.py` - gra w wisielca
- `hangman_art.py` - elementy graficzne używane w grze wisielec
- `hangman_words.py` - lista słów używana w grze wisielec
- `higher_lower.py` - gra typu „wyżej czy niżej”
- `higher_lower_art.py` - elementy graficzne do gry „wyżej czy niżej”
- `higher_lower_data.py` - dane używane w grze „wyżej czy niżej”
- `number_guessing.py` - gra polegająca na zgadywaniu liczby
- `password_generator.py` - generator losowych haseł
